# Native output-contract priority experiment

The semantic parent passes its first original86 screen in every layer, then
fails one separate cookie-scope input because a nested score key is replaced
with a field-specific key. The proposed high-priority format prefix preserves
all four original system bodies after prefix removal and the other five files.
Its actual screen introduces further native parse failures. It is rejected;
its original full150 slot was cancelled before any model call. No parser,
field, enum, model, native recipe, reference or denominator is relaxed.

The installed native judge and structured recipes both require Markdown JSON.
Storage serialization helpers are not replacements for the generation parser.
The local interface inspection changes no runtime code. The admission checks
use actual native audits in CPU-only mode and start no model call.
