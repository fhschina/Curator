## Conclusion

Medium thinking produced 413/480 (86.04%) correct directions and 195/240 (81.25%) correct whole pairs. The fresh OFF control produced 402/480 (83.75%) and 190/240 (79.17%). All invalid and unresolved judgments stay in the fixed denominators with zero credit.

Medium had 3 invalid personal-reference judgments and 0 length-limited calls. It used 3.12 times the native run time and 4.15 times the completion tokens of OFF.

Medium improves both final metrics in both paired repetitions, and aggregate invalid judgments fall from 5 to 3. The first repetition adds 1 invalid judgment, so the frozen per-repeat advance rule is not met; the 90/85 target is also unmet. This diagnostic ends here; retain medium as an unaccepted candidate and report it alongside the OFF baseline. This is a two-repeat development diagnostic, not the original three-repeat acceptance or independent human accuracy. The policy and default OFF setting remain unchanged.

In the primary ON arm, main produced 419/480 correct directions and final produced 413/480. Raw wrong blocks changed from 42 to 56; invalid pairs changed from 2 to 3. These layer snapshots separate the main judgment from changes introduced by later checks.
