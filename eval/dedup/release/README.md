# Judge contract v0.7

This directory contains the immutable prompts, schemas, local-runner configuration,
and 24-pair smoke-panel index selected for Dedup Eval v0.7.1. Runtime outputs must
be written to a user-provided run root; this source directory is read-only.

The v0.7.1 tool preserves Judge contract v0.7 semantics. Its lineage starts at
the original v0.7 release commit `ef17d9b6527532521580781570942728509629bd`.
