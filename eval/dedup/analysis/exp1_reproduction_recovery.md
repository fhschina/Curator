# .33-exp1 同一轮复现的中断恢复

仅修复运行生命周期与断点恢复；原 `exp1_reproduction`、runtime、协议、测试及
全部冻结语义资源保持原字节。原 manifest、初始请求、历史比较、权重和五条排除不变。

恢复前冻结当前请求、响应、结果和进度文件的摘要。已完成结果（包括失败）不重跑；
部分完成样本用本轮自己的已保存响应，从原生解析器开始重放同一条阶段链。
下一条请求必须与该阶段已有请求完全相同；不匹配立即停止，不能转成模型重试。
既有失败响应仍按原规则处理，不能靠恢复重新抽取。没有任何历史版本缓存接入。

仅对没有保存响应的请求重发完全相同的请求体；保留原请求文件，不覆盖结果。
记录每次提交和保存。中断前没有完成事件的调用可能已到达提供方，无法确定是否
计费，必须披露。中断重发与语义重试分别记账，不能声称是无中断的一次性执行。
HTTP 完成事件持续追加；每个恢复会话有独立标识，跨会话总预算保守扣除未知调用。

独立后台会话运行、单进程锁防止重复采集，每 30 秒追加心跳、结束时保存退出状态。
异常退出不自动无限重启；恢复仍需校验全部冻结来源。传输熔断后停止派发剩余样本，
不将整批未发送样本提前记为模型失败。已收到的失败不得删除。

完整收齐之后仍用原离线 audit、原 assess/export 计算分数。另附 recovery_final.json
披露中断、已保留结果和恢复调用。不中途看语义分数、不改 prompt、不改参考、不启动
独立 holdout 或 20k、不发布 release。启动前用本地 HTTP 模拟验证恢复边界，零模型调用。
