# v0.6.2.33-exp2 bounded pilot

The changed unit is the agreed policy plus its typed retention/output contract.
This is not a prompt-only causal estimate and not a new full-development score.
The `.33-exp1` frozen results, default configuration and all historical references
remain unchanged. The V4 reader explicitly delegates V0/V1/V2/V3 to their original
validators; it does not relabel those outputs as V4.

Before inference, freeze all 36 preflight diagnostic cases and 12 synthetic
current-policy protections. Preserve original payloads and the old 995/1000
comparison convention. Synthetic samples are assistant-authored regressions, not
independent human gold, and must not be pooled with original sample weights.
H0130/H0344 remain reference-pending diagnostics; their original yes/yes labels
are retained in the copied reference. No new benchmark exclusions are added.

Run two paired repeats with fresh main, routed coverage, subject and fixed-proposal
verification responses for both arms. Baseline uses `.12` main with v6-route,
retention critic v4, subject scope v2 and fixed verifier v4. Candidate uses the new
retention main/critic and V4 projection, preserving the subject scope and verifier
prompts and proof semantics. Do not reuse old main/critic responses or call the
fixed-upstream historical run a fresh end-to-end result. Both arms use the same
current endpoint/model, temperature=0, top_p=1, max_tokens=4096, disabled thinking,
portable structured-output projection, and complete unchanged payloads. The
baseline native output schema is generated from the original NDD judge recipe.

All 13 truncated and 11 capped-packet cases preserve an explicit unresolved result
without paid inference in either arm. This deterministic admission shortcut is
declared, not a semantic repair or evidence-window expansion. The actual pair
prompt remains span-only. No new full-document main presentation is introduced.
Complete identical nonempty input is a deterministic exact result in both arms;
normalization-only and translated samples still require model judgment.

Offline replay permits only complete exact identity or the existing incomplete-input
abstention. Non-exact old raw ledgers do not supply the new source-loss fields;
mark them UNAVAILABLE_MISSING_RETENTION_PROOF, without inventing witnesses or
publishing a hybrid full score. Historical V4 critic responses do not contain loss
severity/type either; they are not silently promoted into the new contract.

Every submitted stage stores its exact request digest, model response and validation
status. A dependent stage runs only on its own fresh valid predecessor. The critic
can only remove existing positive directions. Subject vetoes need an allowed
binding and the fixed verifier's attestation of both selected actual named targets.
No semantic-repair retries are performed in this first pilot; every invalid answer
is an engineering failure. HTTP retries are bounded at two with a global attempt
budget; the existing credential-safe paced relay is reused. Credentials are never
written in manifests or receipts. Maximum logical calls: 48*2*2*4=768, usually much
less because most cases/stages bypass. Stop online admissions on a transport circuit
failure and retain all unavailable rows in accounting.

Pilot gate, declared before responses: candidate must preserve all 12 synthetic
expectations in both repeats; all seven user-confirmed/exact-companion title cases
must retain the containing side only; there must be no engineering failures, no
candidate repeat-direction changes and no normalized-direction disagreement in
either of the two observed exact-input groups. All other observed disagreements
require cause review before any 1,000-pair admission. Passing numerical pilot checks
alone never automatically launches a full run or release. If it fails, retain the
entire run and review the mechanism before another version or response set.

Full fresh 1,000-pair and independently reviewed 400-case holdout gates from the
checkpoint preflight protocol still apply. The 75% precision/recall requirements
are not relaxed; the pilot's deliberately selected cases are not a population
estimate and do not establish those thresholds. No 20k or MinHash claims here.
