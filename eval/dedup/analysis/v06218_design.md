## 唯一呈现改变

- control：实际 .14 system/pair/rubric、输出列名和所有规则不变。
- ordered：内部实验臂名沿用可重放 presentation assessment 合同；在 .18 中表示下述**局部原文行补充**，
  不是 .17 的全局全文＋短索引。
- 保留原 semantic_diff 中每条完整引用、原顺序、原 span ID。不得用 preview 替代完整引用。
- 对完整且未截断的文本，以现有换行符为边界逐行检查字符区间，不调用语言模型分句或推断 HTML。
  只有一行同时含完整落在该行内的 unique span 和相交的 SHARED span 时，才将该原文行作为辅助上下文展示。
  一行多个片段合并展示一次；附带覆盖该行的已有 span ID 和 Unicode 字符偏移，不创造新证据 ID。
- 原文行长上限 640 字符；超过时只跳过该辅助行，原 span 全文仍在。
  每对辅助行原文总长上限 8,192 字符，超过则整对不加辅助上下文，不截断原 span 或丢掉样本。
  该上限不包含序列化/索引开销，因此最终预算仍必须按真实 renderer/tokenizer 另行检查。
- 不完整输入、无符合条件行或辅助预算不足时，渲染后的 system/user 与 control **逐字相同**，不加空标题或状态提示。
- 本地派生字段不含 main、标签、review ID、hostname、抽样原因或实验臂；模型只看到已有可见文本。
- 不加入 .15/.16 语义补丁，不采用 v9 仲裁，不改 YAML rubric/options，不修改任何历史文件。
