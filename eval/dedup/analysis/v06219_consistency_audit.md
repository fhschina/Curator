# V0.6.2.19：分歧即未决提高了 precision，但没有修好主决策

## 决定

完成 .16/.17/.18 全部 14 个正式 cell 的离线重放，共 3,612 份历史响应，**零新增模型调用**。
107 份响应、11 个 pair ID 满足非正文等价／有证据扩展的结构化分歧条件。
按 [诊断协议](v06219_design.md) 将它们改为未决后，14 组的加权主决策一致率全部下降。
**不将“分歧即未决”接入生产，不晋级，不扩大在线评估。持续目标仍未达标。**

3,612 不是独立样本数：这是同一 258 个 pair ID、230 份不同完整 payload 的重复输出。
不把 AI 开发参照称为独立人工真值，不更改旧 CSV、权重或任何历史实验结果。

## 可重放反事实

[实现](nonmain_consistency.py) 先验证原 run manifest、冻结文件、main、payload、标签及 cell artifact 摘要，
再精确匹配每条已发布 critic 的响应摘要，重放原 v8 public 字段与 evidence。
所有 3,612 条均匹配；没有挑重试、组合回答或重新调用 main。

只有完整、未截断、span 对齐、非 exact、main 两侧 NON_MAIN_ONLY 且宣称完整消息等价、原最终 yes/yes，
以及各字段独立引用合格的 atomic extension + bound record + retained none/not-applicable 才触发。
不读 review ID、标签、语言或自由理由关键词决定结果。
引用有效只证明来源存在，不证明 critic 的语义结论正确；反事实因此只产生 UNRESOLVED，不编造 no/no 或方向。

现有 v3 未决 schema 强制 LOW、extraction-risk 和空 evidence，不能直接表达“完整输入下模型字段冲突”。
本轮如实沿用这一旧输出约束，并在独立诊断字段说明真实原因；原 public、精确 evidence 和 critic 均保留。
这是离线探针，不是已解决此 schema 表达问题的线上新合同。

全部 14 组分别表现为：precision +4.22 至 +7.20 pp，recall −1.33 至 −3.08 pp，主决策 −0.48 至 −1.12 pp。
每组少 5–7 个误合并，同时多 1–2 个参照正例漏判。107 次变化是 89 次 OVER_GROUP→UNRESOLVED、
18 次 CORRECT→UNRESOLVED；**没有一条主决策错误变正确**。这些计数是历史响应事件，不应当作 107 个独立样本。

各组 weighted/unweighted、cohort、置信档、完整保护结果及逐条变化见
[机器可读摘要](v06219_consistency_assessment.json)。precision 超过 75% 不等于同时满足 recall/primary 门槛。

原本失败的保护仍失败，不能据“未新增 guard 错误”晋级。
H0289 三次从参照正确变未决，使对应 translation cohort 的加权主决策降低 9.38 pp。
虽然这些组仍通过较弱的“相对 .12 不低于 −3 pp”历史底线，同响应的真实回退必须单独报告。

## 11 个触发样本的原文核验

本节是预测可见的 AI 诊断，不是盲审，也不改 reference。每个样本至少一份完整三字段 critic 与 ledger
存于摘要的 example_proof_by_review_id；所有 107 份证明存于完整外部 assessment。

| 样本 | 触发次数 / 14 | 可见差异与结论边界 |
|---|---:|---|
| H0363 | 8 | 新增 non-necessary cookie 定义和事先同意要求。critic 明确说是 retained extension，却又因不矛盾给 none；不能直接认定双向覆盖。Read More/Reject 按钮差异不单独构成冲突。 |
| H0688 | 12 | 一侧还有默认同意 banner、必要 cookie 的无个人信息说明及非必要 cookie 定义。应逐命题找对应内容，不能仅凭“标准模板”全忽略。 |
| H0844 | 14 | 除 banner 外还有 non-necessary cookie 定义及同意要求；同样需要区分新增定义/范围和无害控件。 |
| H0955 | 14 | 一侧缺少 banner 与两个 cookie 类别解释；不能用共同总述替代所有类别命题的覆盖验证。 |
| H0906 | 12 | 丹麦语一侧增加技术用途总述、撤回同意的后果、Functional/Always active。应检查哪些被共享正文蕴含，哪些是真实未覆盖状态/说明。 |
| H0856 | 14 | Amanda Warner / Contact Me 对只有机构法律 footer。critic 从 footer 推断同一具体出版物与作者绑定，缺乏双侧独立记录锚点；还涉及短联系人入口是否仅为 chrome，不能机械 veto。 |
| H0702 | 14 | IDX disclaimer 一侧追加日期。原文没有明确标注它是政策生效/版本日期；不能只因日期存在就认定 state change，也不能未经核验认定无害。 |
| H0260 | 1 | 一侧有“请选择要添加的产品”，其余为 cookie 文案。不能把产品选择指令并入 cookie 记录；但是否足够证明实际页面功能，也要遵守不从普通控件推断角色的边界。 |
| H0488 | 14 | 同一订阅/延期购买授权旁有含税、结账计算运费及最小数量验证文字。旧参照明确按通用 checkout chrome 判等价；critic 每次把它叫特定交易扩展。没有具体商品/订单锚点，不能让 atomic 分数自动推翻旧口径。 |
| H0214 | 1 | 完整 cookie 文案外新增默认同意 banner 和 Accept/Reject。旧 .8 AI 参照将其归为 chrome；本次 critic 认为有新同意机制。需要与真正新增访问/同意条件一致解释，不能按是否有利评分处理。 |
| H0289 | 3 | 越南语密码输入与英文“发送设置新密码链接”不是单凭语言就能证明完整翻译；原 translation 标签有争议，但本轮仍原样计为正例，不借争议消除回退。 |

这不是一个能通过扩大 veto 全部解决的同质簇：它同时包含实际未覆盖意义、错误的记录绑定、
普通控件/日期角色不明，以及历史参照边界争议。

## 下一步

1. 保留此探针用于审计，停止把“atomic + none”直接改为未决的候选。
2. 将后续 critic 合同的重点从“有没有矛盾”转为“哪些保留命题没有被另一侧覆盖”：分别给出来源侧、
   原 span、最接近的对侧 span/无对应、差异角色与覆盖结论。无害控件和真正权限/对象/状态需分开。
   先为该合同及路由建立合成测试，再小规模验证；不能把旧自由理由事后补造成新字段。
3. 不新增所有权推断：共享 footer、cookie notice 或“this page”不证明同一特定商品、作者页面或交易。
   非正文有实际意义变化按既有 no/no 政策；真实主内容扩展仍须独立同记录锚点，保护单向方向。
4. H0177/H0634 reference 修订及最多 64 次较大模型诊断仍待用户确认；本轮都未执行。
   新合同开发可以继续离线进行，不以人工口径问题为借口继续无界重复相同提示实验。
5. 最终仍须完整 1,000 条开发集 ≥75% / ≥75% / ≥79% 及保护条件，再过未见 400 条独立人工 holdout，
   最后才是 20,000 对。当前不能声明达到要求，也不能把 AI 自审替代独立标注。
