# Internal Judge v0.7

`v0.7` is the internal release identity for the selected
`v0.6.2.33-exp6+coverage-format-fix1` implementation. It changes only the
recorded runtime version; prompts, schemas, generation parameters, routing,
semantic rules, and bounded recovery behavior are identical to the selected
Exp6 candidate.

The internal release remains provisional until a fresh 20,000-pair run from
this exact commit passes its smoke gate and immutable offline replay. The
independent holdout remains a separate quality gate. Do not create the final
`v0.7` tag from a different commit or by composing historical results with
isolated recoveries.
