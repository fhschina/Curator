# .12 critic scope v1：单因素职责实验协议

状态：实验，非新 release。用户要求基于 .12 调整 critic 的介入范围。

## 不变项

原 .12 主 Judge 的 prompt、rubric、原始响应、可见 payload 和 `v6-route` 主输出完全不变。
逐字段重放 `.12 final` 的 `v6` 仲裁，再单独导出全部 39 条介入案例（21 条按草案计分改对、16 条完全正确变错、另两条发生其他错误转移）。
这 39 条的旧／新参照、原始主／critic 响应、全文及既有复核状态都保留，不将 21 条自动称为独立确认负例。
原 64 条面板所有成员都进入本次候选材料集合；原冻结文件不覆盖。追加六条已复核政策应用和明确的政策主体冲突保护。

历史参照及上一轮五条变更的部分草案均冻结不改。独立新标签为 0；既有 AI 复核和规则应用明确记录 provenance。
部分草案没有把完整 1,000 条重标完，局部得分不作为总体性能或发布证据。

## 唯一语义变量

主输出固定，比较原 .12 critic 与新的 veto-only critic：后者必须举证哪个替代方向会丢失内容，或实际冲突、空实质锚点。
其 prompt、pair prompt 与 rubric 同步表达 `X+独立Y` 和完整相同政策＋商品的允许口径。
不再接受仅凭“并非同一记录的扩展”“独立商品/文章附着”进行全局 NO/NO 否决。

新增内部证明契约 `dedup-v06212-critic-intervention-v1`。旧 critic 响应缺少方向性证明，不能转换或伪装成这个新契约。
它只可移除主 Judge 的 YES 方向，不可创建 YES、恢复主 NO/U 或反转单向方向。
方向内容丢失必须引用将被丢弃侧的 unique span；真正冲突必须有双侧证据和实际 delta；空锚点反驳需覆盖全部 shared spans。
证据结构检查不能证明模型的语义解释正确，仍须保护样本和复核。
显式 ABSTAIN 产生 LOW/UNRESOLVED；语法或证据错误记工程失败，不伪造有效判断，也不默默回退为“正确”。

完整相同原文及主 NO/U 不调用 critic。该路由对两个新调用实验臂完全相同。
相同文本绕过 critic 单独计为工程路由修正，不能和新 critic 语义收益混算。
只改变职责的子实验包括新的结构化证明输出格式；因此不是单句 prompt 编辑的消融实验。

## 冻结的 19 条小试

- 政策＋商品：H0108、H0126、H0419、H0998。
- 原 AI 全文复核明确负例：H0093、H0537、H0701、H0760。
- 实际角色／服务对象／政策主体冲突：H0195、H0514、H0850、H0316。
- 翻译／chrome 保护：H0007、H0893、H0347。
- 完整相同原文的工程路由：H0417、H0810。
- 争议观察项：H0352（短政策完整性）、H0748（Stories 片段及方向口径），不强制追随旧 NO 标签。

19 条均在分母中。主 NO/U、完整相同原文是透明的确定性绕过，不冒充已收到模型回答。
其余各跑原 .12 critic 和 scope-v1 两个臂，各两次；最多 76 个逻辑请求，实际请求数由冻结路由决定。
每轮两臂交错，第二轮交换提交顺序。只传原始可见 span 证据，不传版本、主输出、标签、review ID 或抽样理由。
对照使用原 .12 的 NDD prompt renderer 和两字段输出，候选使用新证明契约。两臂均使用相同 JSON mode 传输包络。
新 .12 对照与保存 .12 分开呈现，避免把服务漂移／重跑变化当候选收益。

NVIDIA 同一配置模型 `nvidia/qwen/qwen3.8-27b`，temperature 0、top-p 1、4096 输出 tokens、thinking 关闭。
使用现有凭据加载器和现有 key，不记录密钥内容。复用既有 pacing relay：间隔至少 2 秒、最多 2 并发、每逻辑请求最多 2 次传输尝试。
输入用已安装的本地 tokenizer 检查，输入＋输出＋2048 reserve 不超过客户端 32768 guard；不截短原文。
本轮 schema correction 重试为 0，以明确暴露新契约稳定性；语义／格式失败照样保存并完成两轮小试，但不扩大。
技术异常、限流耗尽及未完成请求均保留，不能用成功子集冒充完整比较。

## 停止与报告

需要两轮工程完成，四条政策方向目标均符合部分草案、八条明确负例保护均为 NO、五条等价保护保持正确，候选两轮主决策一致。
任一失败即停止扩大，不在已观察的小试中继续编辑 prompt/契约再覆盖重跑。
即使全部满足，也只允许复核局部结果后讨论下一步，不自动启动完整面板、1,000 条、holdout 或 20,000 条。
19 条刻意富集难例，报告加权／非加权值仅作面板诊断；不能替代总体 75% 门槛，也不下调门槛。

交付包括：新代码／prompt／rubric、一对一测试、39 条介入清单、保留 64 条成员的材料集、冻结的原始请求、逐次响应及传输收据、两轮配对评估与不扩大原因（若有）。
