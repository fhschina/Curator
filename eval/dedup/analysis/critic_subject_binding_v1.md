# Fixed-coverage subject-binding diagnostic

The completed source-order trial was rejected after review of all 46 observed
error IDs. Both generic wording changes and presentation changes fail to reliably
distinguish an actual liability subject from branding. This experiment changes
the task boundary: an optional specialist compares only the actual subjects of a
corresponding proposition, over exact saved v4 coverage outputs.

Use the same 96 cases, unchanged partial-draft and historical labels, fixed .12
main, and the two saved encoding-control outputs of the source-order trial. Both
control and candidate use the same saved v4 output for each case/repeat. Only the
candidate adds a fresh subject comparison where that output is positive and the
visible packet has bilateral unique spans. Main-negative, exact, one-sided-only,
and truncated cases are not sent. No raw main or general critic is regenerated.
The specialist never adds a YES direction, reverses containment, or promotes
uncertainty to a conflict. Invalid evidence is an engineering failure, not an
implicit success. Allowed evidence IDs are constrained per side on the wire and
validated against every original span locally.

Use the same NVIDIA model, generation, existing credentials and resilient paced
transport. Freeze requests before calling; deadline is 2026-09-11 12:00:52 UTC,
admission stops 210 seconds earlier. No schema/semantic retries.

Targets: H0606 liability subject. Protect the existing paired-trial target/guard
set plus H0017 additive translation and every previously correct panel case.
Report all 96 denominators, both repeats, newly introduced errors and all output
failures. A stable H0606 repair with zero new clear errors and zero engineering
failures permits a separately frozen full-1000 pipeline diagnostic, not release.
Review all errors first; pending reference disagreements cannot be excluded or
relabelled. This is a causal saved-base ablation, not a fresh three-arm comparison.
